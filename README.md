Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

`main.py` (Python standard library only) writes one funny line, 84 characters, to `/output/entry.txt`:

> I clapped when the plane landed and the pilot announced, "Sir, this is a Greyhound."

The last four words reframe the whole scene — no plane, no pilot, no landing, just a bus and a man clapping at the driver. The line was brainstormed with DeepSeek (8 candidates, critique-picked — see `CANDIDATES.md`).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
